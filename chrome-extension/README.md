# 明猎 Chrome 扩展

明猎 Chrome 扩展是工作台的可选 companion，用于在桌面 Chrome 浏览猎聘简历时快速调用明猎。它不是独立的招聘系统，必须连接正在运行的明猎工作台。

## 什么时候使用

- 在工作台里用一句话启动岗位搜寻和候选人分析：使用工作台即可，不需要安装插件。
- 已经打开猎聘简历详情，想把当前简历保存到某个岗位并提交分析：使用插件。
- 想在浏览器侧边栏查看对话、候选人和招聘进展：使用插件，但工作台仍需保持运行。

## 安装

1. 先按照仓库根目录 [`README.md`](../README.md) 启动明猎工作台。
2. 在工作台进入“设置 → 模型服务”，完成模型服务配置。
3. 进入“设置 → 扩展连接”，生成一个访问令牌并复制。
4. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择当前目录 `chrome-extension/`，不要选择仓库根目录。
6. 点击浏览器工具栏中的明猎图标，在侧边栏“设置”填写工作台地址和访问令牌，点击“保存并连接”。

默认工作台地址为 `http://127.0.0.1:5000`。如果启动时使用了其他端口，请填写实际地址。Chrome 116 或更高版本支持本扩展使用的 Side Panel API。

## 日常使用

### 一句话招聘

打开插件侧边栏，在“助手”面板输入岗位需求，例如：

```text
帮我找深圳的半导体销售总监，先收集 10 份简历。
```

示例提示只会填入输入框，不会自动提交。发送后，搜寻、分析和推荐由工作台执行；切换页面或暂时关闭侧边栏不会取消正在运行的任务。

### 分析当前简历

1. 在猎聘打开一份可访问的简历详情页；
2. 打开明猎侧边栏，在底部选择目标岗位；
3. 点击“分析当前简历”；
4. 回到“候选人”面板查看保存结果和匹配分析。

搜索列表页不是单份简历详情页时，插件不会提交当前页面。没有岗位时可以先在助手中发送需求创建岗位。

## 连接与权限

插件只保存工作台地址、扩展访问令牌、输入草稿和岗位选择。模型 API Key 只在工作台设置，不需要重复填入插件。访问令牌可以在工作台撤销。

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 在 Chrome 侧边栏显示明猎助手 |
| `storage` | 保存连接设置、草稿和待提交简历 |
| `activeTab` | 识别用户当前打开的页面 |
| 猎聘页面权限 | 读取用户当前打开并可访问的简历详情 |
| 工作台地址权限 | 调用本机或用户配置的工作台接口 |

插件不会自动发送猎聘站内消息，也不会把模型密钥放入浏览器端。猎聘页面的登录状态与工作台用于搜寻的浏览器会话可能不同，遇到登录或人工验证时请按页面提示处理。

## 更新与排查

- 更新代码后，在 `chrome://extensions/` 点击明猎的“重新加载”，再刷新已打开的猎聘页面。
- 显示“无法连接”时，确认工作台仍在运行、地址端口正确、令牌没有被撤销。
- 显示“页面未就绪”时，打开猎聘简历详情并刷新页面；搜索结果列表不能直接提交。
- 提交失败时，插件会保留待提交项目。先确认工作台是否已经保存，再点击重试，避免重复提交。

更完整的权限、连接和恢复说明见 [`docs/browser-extension.md`](../docs/browser-extension.md)。

## 本地验证

在仓库根目录运行：

```powershell
python scripts/verify_extension.py
```

验证脚本使用虚构简历和隔离浏览器资料，不访问真实猎聘或外部模型。

## 界面组件授权

插件内的 `ui-components.css` 和 `ui-components.js` 包含针对明猎改造的 React Bits SpotlightCard、StarBorder，授权全文随插件保存在 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。修改组件时，先编辑工作台的 `static/` 源文件，再运行 `python scripts/sync_ui_components.py` 同步插件副本。详细来源见 [组件说明](../docs/ui-components.md)。
