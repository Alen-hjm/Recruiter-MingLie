# 明猎浏览器扩展

Chrome MV3 侧边栏扩展，适合在桌面浏览器中边看简历、边使用明猎。需要支持 Side Panel API 的 Chrome 116 或更新版本，以及同时运行的明猎工作台。

## 安装与连接

1. 在 `chrome://extensions/` 开启开发者模式，加载项目的 `chrome-extension/` 目录。
2. 启动工作台，在“设置 → 模型服务”配置模型。
3. 在“设置 → 扩展连接”生成并复制访问令牌。
4. 点击工具栏中的明猎图标，在侧边栏“设置”填写工作台地址和访问令牌，点击“保存并连接”。

默认地址是 `http://127.0.0.1:5000`。如服务监听其他端口，请使用实际地址。远程部署使用 HTTPS；保存新地址时浏览器可能请求该地址的访问权限。

更新已有扩展：拉取代码，重启工作台，然后在扩展管理页点击明猎的“重新加载”。已打开的猎聘页面也需要刷新，以加载最新页面脚本。

## 日常使用

- **一句话招聘**：在助手中输入岗位、城市和目标，例如“帮我找深圳的半导体销售总监，先收集 10 份简历”。不必先创建岗位；示例按钮只填入输入框，可修改后发送。
- **查看任务**：理解、搜寻、分析、推荐阶段来自工作台的实际执行状态。切换面板或关闭侧边栏不会停止后台任务，再次打开可恢复进度。任务会话保存在服务进程中，工作台重启后不保证恢复这份对话。
- **分析当前简历**：在猎聘打开可访问的简历详情，在插件底部选择岗位，点击“分析当前简历”。插件读取当前详情并保存到工作台，后台分析结果可在候选人页刷新查看。没有配置模型或岗位描述时仅保存简历，并提示补充设置。
- **候选人与跟进**：按姓名、经历、城市搜索，按匹配度筛选，查看分析依据或加入跟进。未分析与低评分会分别显示；评分辅助核实，不直接作录用决定。
- **首次使用提示**：首次打开显示三步说明，可收起；助手底部的“使用引导”可再次打开。

扩展和网页端共享对话；清空对话前会明确提示。提交失败的简历保留在本地待提交列表，网络恢复后可重试。若提交结果不确定，先核对工作台是否已保存，避免重复提交。

## 配置与权限

扩展只需要工作台地址和访问令牌。模型服务在工作台统一配置，不再从侧边栏直连 DeepSeek。旧版保存的凭据不会被自动删除；旧访问 Key 的兼容性取决于后端设置，建议迁移到独立访问令牌。

| 权限 | 用途 |
| --- | --- |
| `storage` | 本地保存连接信息、输入草稿、岗位选择和待提交简历 |
| `sidePanel` | 在浏览器侧边栏打开招聘助手 |
| `activeTab` | 用户使用插件时识别当前页面 |
| 猎聘页面权限 | 在简历详情读取用户当前可访问的页面内容 |
| 本机工作台 / 用户批准的 HTTPS 地址 | 调用对应工作台接口 |

插件不会自动发送站内消息。侧边栏的自然语言搜寻由工作台执行；工作台的采集浏览器会话与当前 Chrome 登录状态可能不同，需要按提示完成登录或验证。

## 常见问题

- **无法连接**：确认工作台已启动、地址端口正确、令牌未撤销，再点击顶部刷新。
- **页面未就绪**：更新扩展后刷新猎聘页面，并打开简历详情；搜索列表不能作为单份简历提交。
- **缺少模型配置**：在工作台设置模型服务，扩展无需重复填 Key。
- **一直等待进度**：确认工作台仍在运行。连接恢复前避免重复发送同一需求，已有后台任务可能仍在执行。

## 本地验证

```powershell
python -m pytest
python scripts/verify_extension.py
```

前端验证脚本需要 Playwright 和 Chromium。它使用虚构数据、独立临时浏览器资料和拦截的网络响应，覆盖侧边栏交互与真实 MV3 包加载、令牌请求头及内容脚本通信，不访问真实猎聘或外部模型。截图保存在忽略提交的 `data/extension-preview/`。
