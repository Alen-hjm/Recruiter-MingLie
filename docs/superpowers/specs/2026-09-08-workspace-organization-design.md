# WorkSpace 工程整理设计

## 目标

将 `D:\extension\WorkSpace` 确立为明猎 AI 招聘工作台的唯一主项目。在不改变现有业务能力、AI 评分逻辑或敏感采集行为的前提下，补齐运行边界、环境说明、依赖声明和最小自检，使项目可被安全地安装、启动和维护。

旧项目 `D:\extension\minglie-scraper` 不在本次范围内。

## 当前边界

源码由 Flask 服务端、SQLite 数据访问层、JD/简历 AI 分析、知识库、Chrome 扩展和猎聘采集器构成。当前仓库还包含浏览器会话、候选人导出、SQLite 数据库和截图等运行时产物。

本次不修改：

- `app/scraper_liepin.py` 及 `app/anti_detect.py` 的采集、浏览器控制或反检测逻辑；
- AI 模型的评分规则、提示词或业务接口行为；
- SQLite 中既有候选人、账号或任务数据；
- Chrome 扩展功能和页面交互。

## 设计

### 目录与运行时数据

保留现有源码目录：`app/`、`templates/`、`static/`、`chrome-extension/`。

增加 `instance/` 作为今后的本地运行根目录，约定数据库、导出、截图、浏览器会话和日志均放在其中。为避免破坏已有用户数据，本次不会移动或删除 `data/`、`browser_data/`、`screenshots/`；运行代码将继续兼容它们。

`.gitignore` 将排除所有运行时数据、浏览器会话、数据库、候选人导出、截图、缓存、虚拟环境与本地环境变量文件。`*.example` 配置文件可以被提交，真实配置不进入版本控制。

### 配置与依赖

增加 `.env.example`，集中说明端口、Flask 密钥、数据库路径、AI 服务地址与模型名称等部署参数。真实 `.env` 由本机提供。

增加可复现的 Python 依赖清单，涵盖 Flask、Flask-Login、Flask-CORS、HTTP 客户端、Playwright、Rich 和 WebSocket 客户端。不会锁定平台相关的浏览器二进制；文档将单独列出 Playwright 浏览器安装命令。

### 可运行性

保留 `run.py` 作为启动入口。新增最小自检命令，只验证：应用模块可导入、数据库目录可创建、数据库可初始化、模板目录存在。自检不启动 Web 服务、不访问外部网络、不启动浏览器，也不写入候选人数据。

### 文档

增加 README，覆盖项目模块图、前置条件、安装、初始化、启动、Chrome 扩展加载方式、运行时数据位置和自检命令。

## 验收标准

- 克隆后的仓库不包含浏览器会话、真实数据库、候选人导出或截图。
- 按 README 创建虚拟环境并安装依赖后，可运行数据库初始化与最小自检。
- `python run.py` 仍以现有默认端口启动工作台。
- 现有采集、AI 评分、服务端 API 与 Chrome 扩展接口不发生功能性变更。

## 后续路线（不在本次实施）

后续由用户从三条路线中选择一条：AI 评分可信度、候选人工作台效率、数据接入稳定性。
