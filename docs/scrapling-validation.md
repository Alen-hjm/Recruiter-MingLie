# Scrapling 采集模式与验收

这是可选的 Scrapling 会话适配器，支持 `AsyncDynamicSession` 和使用 Patchright 的 `AsyncStealthySession`。复用项目的搜索、详情提取、逐条保存和任务恢复流程。默认仍为 `browser`。

## 安装与切换

```powershell
python -m pip install -r requirements.txt -r requirements-scrapling.txt
python -m playwright install chromium
$env:MINGLIE_SCRAPE_MODE='scrapling'
# 使用 Stealthy 模式时额外安装它使用的 Chromium：
python -m patchright install chromium
$env:MINGLIE_SCRAPLING_ENGINE='stealth'
```

然后使用项目原有启动命令启动服务。此开关由部署人员设置，不增加客户需要理解的专业参数。登录资料保存在每个用户专用目录下的 `scrapling` 子目录，不复制个人浏览器配置。新会话首次登录最多等待 2 分钟。

默认引擎为 dynamic；stealth 使用库自带的浏览器实现，登录目录为独立的 `scrapling-stealth` 子目录。不添加自定义网站脚本屏蔽或指纹补丁，关闭自动验证码处理。资源正常加载，取消默认 Google Referer，最多尝试一次。Scrapling 会吞掉 `page_action` 中的异常，本项目明确保留并重新抛出它们，确保白屏进入待处理状态。

## 最短实站流程

```powershell
python scripts/verify_scrapling.py --keyword 'Python 开发工程师' --data-dir ./data/scrapling-validation
# 只观察入口 60 秒，不需登录、不搜索：
python scripts/verify_scrapling.py --engine stealth --entry-only --data-dir ./data/scrapling-stealth-validation
# 再验证登录后的单份完整流程：
python scripts/verify_scrapling.py --engine stealth --keyword 'Python 开发工程师' --data-dir ./data/scrapling-stealth-validation
```

人工登录 → 搜索页持续检查至少 60 秒 → 输入关键词 → 最多尝试打开一份详情 → 读取并返回搜索页。仅处理一页，最多保存一份简历，不调用模型、不发消息、不翻页。任何阶段白屏或要求验证就停止；未取得完整详情不算通过。登录浏览器随本次验证结束而关闭，登录资料保留以供下一次人工启动复用。

验证脚本的登录阶段现在提供最长 5 分钟的人工接管窗口：停留在猎聘安全验证域名时不点击、不刷新、不开始搜索，等待用户完成验证并返回。连续两次确认登录后才进入搜索。白屏仍立即终止；搜索或详情阶段的验证仍停止采集。常规后台任务默认登录等待仍为 2 分钟。

本地导航记录在验证数据目录的 `diagnostics/`，仅保存相对时间、阶段、页面类别和异常类型，不保存完整 URL、Cookie、请求头、响应正文或日志文本。简历与截图仍属于私有运行数据，应保留在被 Git 忽略的数据目录中。

## 验收边界

自动化单元测试不证明猎聘访问正常。实站必须分别核验持续停留、搜索、详情与返回。只有最短流程通过后才扩大到翻页、去重及 JD 分析；城市筛选与真实页面选择器仍需验证。

## 操作节奏更新

新增独立 `InteractionPacer`，通过兼容名 `HumanPacer` 接入普通和 Scrapling 采集流程。搜索输入框、详情入口和翻页按钮统一执行：操作前停顿 → 检查页面 → 滚动至目标 → 悬停 → 停顿 → 再检查页面 → 元素定位点击。搜索提交也计入操作次数。没有增加随机坐标、虚假鼠标轨迹或网站脚本修改。

| 阶段 | 内置随机范围 |
|---|---|
| 关键操作前 | 0.8–1.8 秒 |
| 悬停后 | 0.2–0.6 秒 |
| 按下到释放鼠标 | 60–140 毫秒 |
| 详情加载后 | 3–6 秒 |
| 两份详情之间 | 2–4 秒 |
| 翻页确认后 | 3–5 秒 |
| 每完成 6–10 次关键操作 | 下次操作前休息 10–20 秒 |

这些是额外间隔，实际操作仍需等待页面加载与元素可点击。休息阈值只在初始化和完成休息后生成一次。30 分钟上限进入待人工处理，保留结果，不将中断报为完成。所有参数内置，不增加客户设置负担。
